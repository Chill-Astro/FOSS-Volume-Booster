## USAGE :

> [!NOTE]
> THIS EXTENSION DOES NOT WORK ON CHROMIUM ON MOBILE!

 STEP 1 : Clone this Repository :

      git clone https://github.com/Chill-Astro/FOSS-Volume-Booster.git

      cd FOSS-Volume-Booster

---

**CHROMIUM** :
<br>

 STEP 2: Enable `Developer Mode` in Extension Settings.

 STEP 3 : Import `/src` Folder & Enjoy!

 ---

**FIREFOX** : 
<br>

 STEP 2 : Convert `/src` to a `<file_name>.zip`.

 STEP 3 : Go to `about:debugging` > `This Firefox`

 STEP 4 : Click on `Load Temporary Add-on` and Enjoy! ( Until App Restart )
